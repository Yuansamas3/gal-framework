# 现代轻小说 / 视觉小说日常喜剧翻译规范 (`zh_light_novel_v2`)

> 适用题材：现代校园、恋爱喜剧、日常萌系、轻奇幻视觉小说（日译中）。
> 综合提炼自传统反翻译腔准则与现代 ACG 轻小说语感平衡法。

---

## 核心定位与优先级

核心要求：**忠于原意，拒绝生硬翻译腔；说自然顺口的现代“人话”，保留轻盈阅读感与 ACG 角色风味，绝不滥用易过期的中国网络烂梗。**

发生冲突时按以下顺序取舍：
1. 原文情节事实、命题逻辑、否定作用域与控制符完整性。
2. 人物性格辨识度（傲娇、三无、死党、大小姐等）、情绪张力与画面感。
3. 自然、轻快、能顺口配音朗读的现代中文日常口语。
4. 保留恰当的 ACG 文化风味（如前辈、社团、学园语境），但句法必须彻底中文化。
5. 日文表层语序、主被动与前置修饰链，该拆就拆，该转就转。

---

## 总原则

1. **先化，再译**：脑海中先出现立绘、语音、表情与停顿，再敲下中文，而不是逐词置换。
2. **轻盈通透，拒绝厚重**：视觉小说依赖文本框节奏与快读体验。少用生僻字、文言虚词和高考作文四字成语堆叠；能两句短句说清的，绝不憋成一句 35 字的长定语。
3. **拥抱日常感，克制公文书面语**：高中生与现代年轻人说话不该像新闻联播或学术报告。除非角色本身是古风/贵族/学究设定，对话一律自然口语化。
4. **禁止“烂梗排泄”**：允许鲜活口语，但严禁擅自塞入与原作年代或语境违和的中国网络热梗（如：绝绝子、蚌埠住了、泰裤辣、家人们谁懂啊、yyds、社死、小丑竟是我自己等）。
5. **严禁临床/机械语域错位**：亲密或感官描写须紧贴人物情绪与日常体感词汇，严禁混入法医临床词（如「分泌物」「黏膜组织」「括约肌」）或五金机械喻（如「活塞运动」「齿轮咬合」「液压」）。

## 叙述与描写规则

### 1. 多用实在动词，砍掉“弱动词 + 抽象名词”
- ✖ 他对我的提议作出了拒绝。 / 我们对计划进行了确认。
- ✔ 他拒绝了我的提议。 / 我们确认了计划。

### 2. 打碎日文“前置修饰语高塔”
日文习惯把一整串定语挂在名词前面，中文须先立人物/主干，再顺势铺开细节：
- ✖ 那个昨天还在和我吵架今天却红着脸递给我便当的青梅竹马。
- ✔ 我的青梅竹马昨天还在跟我吵架，今天却红着脸，递给我一份便当。

### 3. 消除典型翻译腔信号
| 高危结构 | 反例 | 改写方向 |
| --- | --- | --- |
| 代词冗余 | 他把他的手插进了他的口袋。 | 他把手插进口袋。 |
| 介词腔（关于/对于/由于） | 关于那件事，我感到很抱歉。 | 那件事，真的很抱歉。 |
| 被动照搬 | 他被大家所讨厌着。 | 大家都讨厌他。 |
| 复数滥加“们” | 学生们都看向了我。 | 全班都看了过来。 |
| “的/地”发黏 | 带着难以置信的表情的她缓慢地转过了头。 | 她神情错愕，慢慢转过头来。 |
| 连接词堆砌 | 因为下雨了，所以我们取消了出行。 | 下雨了，我们取消了出门的打算。 |

## 对话与角色声音（重中之重）

### 1. 角色必须有独立“语音库”
遮住说话人名字后，仍应能从句长、用词粗细、直接程度与情绪外露分辨角色：
- **傲娇**：口是心非、急躁掩饰、句尾带点硬撑（「才、才不是特意给你做的！」）。
- **三无 / 冷淡**：句短干脆、零冗余语气词、直述事实（「了解。我去处理。」）。
- **死党 / 轻浮**：用词随意、多反问和快节奏吐槽（「喂喂，你小子也太惨了吧？」）。
- **大小姐 / 礼貌役**：矜持得体、略带正式感但不说古文（「这点小事，哪用得着我亲自动手。」）。

### 2. 吐槽（ツッコミ）要快、准、狠
- 原文：`おいおい、それは冗談だろう。`
- ✖ 太书面：哎呀，你这莫非是在开玩笑吗。
- ✖ 太烂梗：不是哥们，你这波纯纯搞笑男吧？
- ✔ 最适平衡：喂，你开玩笑的吧。 / 拜托，别闹了。

### 3. 节制语气词，用节奏与停顿立空气感
- 不要把 `ね/よ/わ/さ/かな` 机械对应成满篇「呢、啦、哦、呀、哟」。
- `ええと`、`あの` 视语境化作「呃……」「那个……」「我说……」或直接留白。
- 情绪爆发与快节奏吵架用短句推进，平均逗号分句控制在 `18` 字以内。

## 技术性硬底线

1. **外层对话引号由系统剥壳扣回**：工作包 `POST_SRC` 已剥去外层 `「…」`/`『…』`，补丁提交纯净内核即可，勿重复套外层引号。
2. **控制符 100% 原样保留**：`<size=...>`, `[ruby ...]`, `\n`, `%123;` 等引擎标记一字不差保留。
3. **零日文与附着记号残留**：严禁残留假名及 `っ/ッ/ー/・/゛/゜`。
4. **严格遵守本批 `<glossary>`**：无条件词条必须精确落地，避免同词异译。

**最终准绳：让角色在现代中文语境里，用最贴合他们性格与关系的口吻，自然鲜活地再活一次。**
