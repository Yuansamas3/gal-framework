# 古风 / 和风剑戟 / 西式奇幻宫廷翻译规范 (`zh_classical_fantasy`)

> 适用题材：时代剧、和风剑戟、阴阳奇谭、中世纪西幻、宫廷权谋、史诗奇幻视觉小说（日译中）。

---

## 核心定位与优先级

核心要求：**古雅而不晦涩，庄重而不僵硬。依角色出身与阶层精准拉开语域梯度，以节奏与礼法立起时代质感，严禁现代口癖与网络词出戏。**

冲突裁决顺序：
1. 设定事实、世界观专名、阶层伦理与控制符完整性。
2. 角色身份、礼法层级、主从关系与仪态声音。
3. 典雅流畅、合乎中文古白话或典雅译文审美的表达。
4. 剑戟对决的凛冽气势与宫廷交锋的含蓄机锋。

---

## 语域分流指南

### 1. 和风剑戟 / 时代剧线
- 叙述采**典雅半文言或凝练古白话**，重金石声与动作利落（如「刀光一闪」「收刃入鞘」「夜色如墨」），避免生造晦涩僻字。
- 称谓与敬谦按身份严格区分：主君 / 殿下 / 大人 / 阁下 / 师父 / 在下 / 鄙人 / 贫僧 / 奴婢 / 吾辈 / 尔等。
- 保留恰当和风器物与制度质感（如幕府、大名、武士、妖怪、结界、神社、太刀），不强行套用中国明清特有官职混淆世界观。

### 2. 西式奇幻 / 宫廷骑士线
- 采用**古典译制文学的庄重白话**，兼顾优雅仪态与史诗感，避免中式江湖黑话（如把骑士誓言译成“哥们义气”）。
- 称谓依爵位与亲疏严格统一：陛下、殿下、阁下、卿、爵士、大人、阁下之名、吾主。
- 魔法、咒文、圣遗物、种族、公会与招式命名遵循**构词系列化与层级辨识度**，严格服从本批 `<glossary>`。

## 阶层声音对照

同一句意思（如「请停步」），不同身份应呈现截然不同的声音梯度：
- **君王 / 霸主**：「止步。」 / 「退下，休得放肆。」
- **骑士 / 侍臣**：「还请留步，大人。」 / 「在下斗胆，请阁下三思。」
- **市井 / 佣兵**：「慢着！」 / 「喂，站住，话还没说完呢。」
- **古神 / 妖魅**：「且慢……汝以为走得了么？」

---

## 严禁出戏词（绝对红线）

在古风/和风/西幻语境中，以下现代词汇一律禁止出现（除非作品本身明确设定为穿越/现代元素）：
- **现代网络词 / 饭圈词**：社死、内卷、躺平、破防、CP、PUA、yyds、吐槽、打卡、翻车、离大谱、绝绝子。
- **现代校园 / 职场词**：学长、学姐、学弟、学妹、社团、KPI、加班、手机、电脑、拉黑、点赞。
- **现代轻浮口头禅**：欧尼酱、拜托啦、搞什么鬼、啥玩意、超赞、太牛了。

---

## 动作与韵律

- 剑戟与魔法交锋讲究短促凌厉与动词精准，切忌堆砌冗长修饰语或“进行了斩击”“作出了防御”等现代公文腔。
- 咏唱、箴言、碑文与誓词须注意对仗与音律停顿，读来须有仪式重量。
- 放行合理的文言虚词与雅语（如「之、乎、亦、乃、遂、颇、岂料」），但仍以**读者一眼读懂、朗朗上口**为底线，不堆砌掉书袋的生僻冷典。

**最终准绳：让文字自带时代风云与礼法重量，既不浮于现代轻佻，也不陷于诘屈聱牙。**
